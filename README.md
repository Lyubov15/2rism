# 2Rism — Travel Discovery Website

**2Rism** — многостраничный по структуре лендинг туристического сервиса для поиска вдохновения и знакомства с направлениями для путешествий. Главная страница объединяет подборку популярных мест, отелей, ресторанов и активностей, а также блоки с советами для путешественников.

[Открыть сайт](https://lyubov15.github.io/2rism/)

## Возможности

- Главный экран с навигацией и формой поиска путешествий.
- Карточки популярных туристических направлений.
- Подборка отелей и ресторанов с рейтингами и местоположением.
- Разделы с туристическими советами и активностями.
- Блок с информацией о проекте и форма подписки на рассылку.
- Адаптированная мобильная навигация с бургер-меню.
- Элементы выбора даты, активности и местоположения.

## Технологии

- HTML5 — семантическая структура страницы.
- CSS3 — стилизация и адаптивная верстка.
- JavaScript (ES6) — интерактивные элементы интерфейса.
- autoComplete — подсказки при вводе местоположения.
- Custom Select — оформление выпадающих списков.
- easepick — выбор даты.
- SVG — иконки интерфейса.

## Запуск проекта

Проект не требует сборки. Чтобы посмотреть сайт локально:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Lyubov15/2rism.git
   ```
2. Откройте папку проекта.
3. Запустите `index.html` в браузере. Для корректной работы ресурсов и скриптов можно использовать Live Server.

## Структура проекта

- `index.html` — разметка главной страницы.
- `css/` — стили и адаптивные правила.
- `js/` — JavaScript для интерактивных элементов.
- `img/` — изображения проекта.
- `icons/` — SVG-иконки.
- `libs/` — подключаемые библиотеки.
